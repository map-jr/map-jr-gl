Benchmark against MapLibre GL JS

The page runs MapLibre GL JS and this library (the entry @map-jr/map-jr-gl/maplibre-compat, on the main thread and in a worker) one after another in this browser, on the GPU of this device, with the same style and the same views. Keep the tab in front and do not touch the map while it runs. Each scenario runs as many times as "Runs" says, and the table gives the median and the range (lowest to highest) over the runs.

A page cannot read the memory of the browser's processes, so the page does not report memory. The lifecycle scenario counts the workers that the page started and that were not ended instead.
